# Reviewed public aggregates only

This directory is intentionally empty of results until `publish prepare` creates a fresh,
allowlisted aggregate export and that exact export passes privacy, provenance, rights, and
human/agent review.

Raw prompts, responses, reasoning, datasets, local instance IDs, private paths, operator
timestamps, credentials, and dashboard output never belong here. Synthetic examples must be
labeled `mock` and must not resemble measured capability claims.
