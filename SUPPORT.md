# Support

Use GitHub Issues for sanitized, reproducible bugs and Discussions only after a moderation
owner is verified. Security reports belong in private vulnerability reporting.

Include:

- project version and operating-system family (not hostname or hardware serials);
- LM Studio application/CLI/runtime versions and a generic model key if disclosure is safe;
- the command and a synthetic minimal input;
- redacted error category and whether the run was mock or local measurement.

Do not include `.env` contents, tokens, absolute home paths, raw prompts/responses,
restricted tasks, screenshots of the desktop, model files, or external-state archives.
The project cannot support cloud provider calls, self-hosted CI, or host execution of
model-generated code.
